# 🐾 DogShop - Tienda Virtual para Perros

Proyecto académico de desarrollo web Front-End para una tienda virtual de productos caninos (alimento, camas, accesorios de paseo y juguetes).

## 📁 Estructura del Proyecto

- `index.html`: Estructura principal con etiquetas semánticas de HTML5.
- `css/style.css`: Estilos con CSS3, Flexbox, CSS Grid y diseño responsivo (Media Queries para computador, tableta y teléfono móvil).
- `js/script.js`: Interactividad de la página (filtro por categorías, favoritos, carrito de compras y formulario de contacto).
- `img/`: Imágenes de los productos y recursos gráficos de la tienda.

## ⚙️ Funcionalidades

1. **Catálogo con filtros**: Permite filtrar los productos por categoría (*Alimento*, *Descanso*, *Paseo*, *Juguetes y Cuidado*).
2. **Carrito de compras**: Agrega o elimina productos y calcula automáticamente el total a pagar.
3. **Favoritos**: Permite marcar productos favoritos y actualiza el contador superior.
4. **Diseño Responsivo**: Adaptado a resoluciones de escritorio, tableta (`1024px`) y móvil (`768px`) con menú desplegable.
5. **Formulario de Contacto y Pedidos**: Validación de campos y mensaje de confirmación al enviar.

## 🚀 Cómo ejecutar el proyecto

Abre el archivo `index.html` directamente en cualquier navegador web moderno.
